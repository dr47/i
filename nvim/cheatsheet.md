# Tahák — Neovim + CodeCompanion

`_` = spacebar · `C` = Ctrl · `+` = press together.
Sequences such as `C + ww` mean `Ctrl+w`, then `w`.

## Chat

| Shortcut / command | Action |
| --- | --- |
| `?` | Shortcuts |
| `#` | Context |
| `/` | Commands |
| `C + s` | Send |
| `ga` | Change model |
| `/buffer` | Select buffer |
| `/file` | Select file |
| `/save` | Save chat |
| `/resume` | Resume chat |

## Windows

| Shortcut | Action |
| --- | --- |
| `C + w` | Help |
| `C + ww` | Switch window |
| `C + wx` | Swap windows |
| `C + ←↓↑→` | Resize |
| `_w` | Help |
| `_wm` | Maximize / restore |

## Files / buffers

| Shortcut | Action |
| --- | --- |
| `__` | Open file |
| `_f` | File/find help |
| `_fB` | All buffers |
| `_,` | Buffer list |
| `H` / `L` | Previous / next |
| `_b` | Help — unverified |
| `_bd` | Delete buffer |

### Editing

| Command / shortcut | Action |
| --- | --- |
| `:e` | Edit |
| `za` | Toggle fold |

## Sessions

| Shortcut | Action |
| --- | --- |
| `_q` | Menu |
| `_ql` | Load last session |
| `_qS` | Select session |

Save chat separately — it is not included in the Neovim session.
